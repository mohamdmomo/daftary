# 📒 دفتري

تطبيق بسيط لإدارة الحسابات والمصاريف.
عملته لنفسي، ولقيت إنه مفيد، فقررت أشاركه.
بيشتغل بدون إنترنت، وكل بياناتي محفوظة على جهازي لوحدي.

---

## 🎯 الفكرة

بنيت دفتري على فكرة **الحسابات المستقلة** — كل حساب عالم لوحده.
مش عايز أعمل خلط بين حساباتي، فخليت كل واحد له:

- رصيده الخاص
- حركاته الخاصة
- أرشيفه الخاص
- لونه المميز

### عندي 3 أنواع حسابات:

| النوع | بيحسب إيه | الرقم الأساسي |
|---|---|---|
| 👛 **مصروفاتي** | مجموع اللي بصرفه | إجمالي الصرف |
| 🤝 **فلوس مع حد** | دفعتله − اتصرف | الباقي معاه |
| 📒 **حاجة تانية** | مجموع الصرف | الإجمالي |

**مثال من حياتي:**
- **مصروفاتي** — كل يومياتي (أكل، مواصلات، فواتير)
- **فلوس مع أحمد** — عهدة الشغل، بديه فلوس يصرف ويجيب فواتير
- **العيد** — بحوش فيه للعيد، وعارف كل حاجة بتتصرف فين

كل واحد مستقل، مش بيتداخلوا مع بعض خالص.
